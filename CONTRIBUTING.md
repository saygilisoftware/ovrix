# Katkıda bulunma

1. [BUILD.md](docs/BUILD.md) ile Windows x64 derlemesini ve temel testleri çalıştırın.
2. İngilizce kaynak kod ve Türkçe proje dokümantasyonu kullanın.
3. GUI seçeneklerini gerçek motor davranışına bağlayın. Bağımlılık eklerken lisans ve bakım durumunu belgelendirin.
4. Değişen modülün regresyonunu, test donanımını ve gözlemlenen sonucu açıklayın. Donanım gerektiren senaryoları [TESTING.md](docs/TESTING.md) ile güncelleyin.
